# 0.1.0 支持边界与后续验收

## 已关闭的开发验收项

- 五槽/不可变快照/权限闭包、控制面/发送屏障、故障重试与未知状态不重放已有回归。
- 根级观察日志已补齐“工厂尚无Session”及“repository已关、owner未释”的已观察B→C交接；真实Native close-tail注入验证owner保留，最新C不能覆盖未审计B。
- 独立embedding维护追踪真实SDK结算，unknown修复阻断purged。真实公共rechunk/provider=none通过，不据此宣称真实向量供应商通过。
- 可启用Native入口已在隔离Ctx/真实knowledge/loopback网关完成依赖注入、身份、停止/卸载；默认仍不开启。
- 开发候选包已实际验证exports/locale/icon/锁快照及隔离profile安装/合成/默认禁用挂载/卸载；最终包校验见随附清单。

## 明确不承诺

1. 未观察离线策略历史无法由公共Volatile.get重建；未flush观察在根/进程丢失后是UNKNOWN，不是持久撤权成功。日志为64策略/1MiB/8store的根级有界元数据，不是无限审计库。
2. 关闭后又观察到策略会保留owner，可能要求同持锁所有权的受信维护；不提供force-unlock。不能删除锁或重启后直接宣布已修复。
3. 整目录旧备份（含旧ledger）一起回滚无法可靠检出，不支持安全开放恢复。须独立保全最新删除水位。
4. 全历史穷尽摘要、自然语言真实性、2万条及更大库吞吐未承诺；删除批数上限不等于枚举读取/CPU上限。
5. 内存供应商窗口跨配置Session共享，但整个dependency scope/插件/进程重启不连续。持久任务成本不重置。
6. Windows owner-only DACL与可信本地盘是外部部署前提；6项平台/权限分支跳过，不据mode位认证DACL。
7. OCR/native模型peer冲突、真实模型/embedding/rerank和真实QQ发送未授权测试。SnowLuma仅只读登录/元事件已验证，没收到聊天消息。
8. 图标/设置表单资源已经离线检查；当前GUI未安装本插件，浏览器渲染未认证。

最新测试数和分层证据见[验证记录](verification.md)；配置与安全操作见[部署指南](deployment.md)、[交接协议](configuration-observations.md)。
